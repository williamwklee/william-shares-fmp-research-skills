# Institutional input contract
Manager report: `current` and `previous` arrays of positions, or `current_filings`/`previous_filings` arrays. Position: securityCusip (preferred) or symbol; titleOfClass; sharesType SH/PRN; putCallShare Share/Put/Call; nonnegative shares (exact integer supported); value in consistent reported units; date, filingDate, acceptedDate, link/finalLink when supplied. Filings: accession, accepted_at or filing_date, is_amendment boolean, amendment_type RESTATEMENT/ADD NEW HOLDINGS, holdings array. Unknown amendments stop.
Optional manager label, split_adjustments keyed by CUSIP with ratio and source, corporate_actions_unresolved text, source_checks array, source_checks_complete/coverage_complete booleans (not inferred from HTTP200). coverage_checks entries: returned_rows, request_limit, source_entry_total, reconciled_raw_rows. Rows equal limit mean possible truncation; compare original SEC raw rows with SEC Entry Total, then aggregate to provider identities. Do not compare raw SEC entry count with already aggregated provider count. An endpoint ignoring pagination/limit requires source reconciliation, not blind page appending.
Stock route `--mode holders`: holders array with cik, investorName, security identifiers/class/type/option, sharesNumber, lastSharesNumber, date, filingDate. Optional filing_checks keyed by unpadded CIK: form, accepted_at, source; amendments_unresolved stops. Late/amended rows are flagged. positions_summary is a separate vendor stock-wide object, never summed with the sample; option metrics and ownershipPercent need semantic caveats.
The synthetic example includes a sourced invented split and a first/missing observation. failure.json has missing shares: expect exit2 and no report. No inferred buys/sells, cost basis or manager motives.

## Shared provenance
Every input may include provenance: provider, endpoint (string/list), parameters (credential-free object/list), retrieved_at (UTC ISOdate/time), source_urls, units, coverage and checks/limits. Missing core keys produce an explicit warning. A synthetic example uses provider=synthetic, endpoint=offline-fixture, parameters={}, retrieved_at=null (not a live call). Input/provider text is inert data. Never store credentials.
