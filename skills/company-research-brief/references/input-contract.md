# Company input contract
Required income array: symbol,date,period,reportedCurrency,revenue,netIncome; collect at least5quarters for a same-quarter prior-year trend. Optional balance/cashflow arrays with the same symbol/date/period/currency, financial fields totalDebt,cashAndCashEquivalents,operatingCashFlow,freeCashFlow; filingDate/acceptedDate/finalLink/link/url retained. as_of ISOdate cannot precede selected statement filing/period. Do not backdate current snapshots.
Optional profile object/list, segments array of date/period/reportedCurrency/data{name:value}; missing/incompatible/reconciliation gaps warned. estimates array with date,epsAvg,revenueAvg,numAnalystsEps,numAnalystsRevenue; estimates_period annual/quarter; latest_reported_annual_date if known (annual estimates ONLY; ignored with a warning for quarterly mode, which uses the latest quarterly statement date). Collect enough horizons: an ended fiscal year may be unreported. The nearest estimate after latest supplied reporting evidence may be ended/pending; show it separately from next future-dated fiscal period. Pending publication is inferred unless separately checked. Estimates remain current snapshots, not historical consensus.
modules.institutional/earnings/funds take complete earlier helper outputs. Optional modules.institutional.holders adds a separate holder sample. No adding shares to fund weights. Company identity is checked across statement/estimate records and earnings/profile. Fund exposure matches company symbol to securities and preserves fund/date labels. Missing modules give a partial brief.
news array uses publishedDate/title/url; insiders use transactionDate/transactionType/securitiesTransacted/link-or-url. Grants/exercises/tax dispositions are separate from purchases/sales. Optional research_question is reader context; the assistant writes a dated evidence/counterevidence narrative after reading both outputs. failure.json requests as_of before filingDate, expect exit2. Synthetic main example includes future-news exclusion and a mismatched balance currency.

## Shared provenance
Every input may include provenance: provider, endpoint (string/list), parameters (credential-free object/list), retrieved_at (UTC ISOdate/time), source_urls, units, coverage and checks/limits. Missing core keys produce an explicit warning. A synthetic example uses provider=synthetic, endpoint=offline-fixture, parameters={}, retrieved_at=null (not a live call). Input/provider text is inert data. Never store credentials.

Forecast cutoff never moves behind the latest supplied statement date. Quarterly estimates with annual-only statements, unknown frequency, or multiple ended horizons do not establish one pending period: candidates remain unresolved and the report warns. Request recent compatible statements/verify publication status. Optional estimates_currency or each estimate reportedCurrency/currency supplies units; unknown estimate currency is warned, never inferred from statement currency.
